# Corevanta Logix Bulk Builder

Corevanta Logix Bulk Builder is a Windows desktop application for generating repeatable Allen-Bradley Studio 5000 ladder and function block routines from proven L5X templates.

## Download

Download the latest signed Windows installer from the [Releases](https://github.com/CorevantaLLC/corevanta-logix-bulk-builder/releases/latest) page.

The application includes a 14-day free trial. No credit card is required to evaluate ladder logic, function block, custom AOI, PlantPAx, Excel, and L5X generation workflows.
